# Homebrew Tap for CandleKeep CLI

This is the official Homebrew tap for [CandleKeep CLI](https://www.getcandlekeep.com/cli).

## Installation

```bash
brew tap CandleKeepAgents/candlekeep
brew install candlekeep-cli
```

## Updating

```bash
brew upgrade candlekeep-cli
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `candlekeep-cli` | CandleKeep CLI - Manage your document library from the terminal |

## Platform Support

- macOS (Apple Silicon / ARM64)
- macOS (Intel / x86_64)

For other platforms (Linux, Windows), use `cargo install candlekeep-cli` or download binaries from [GitHub Releases](https://github.com/CandleKeepAgents/candlekeep-cloud/releases).
